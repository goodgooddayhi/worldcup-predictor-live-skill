# 多因子公式参考

来源：用户提供的 12 张公式图。图片本身标注“个人兴趣爱好，不具备参考意义”，因此本文件只作为启发式校准层，不作为确定模型、投注依据或替代实时赛果/阵容情报。

## 一、总权重

某队胜率先验可按以下权重构建：

| 因素 | 权重 | 说明 |
|------|------|------|
| 球队实力 | 35% | 两队 FIFA 积分差 |
| 排名差 | 15% | 两队 FIFA 排名差距 |
| 球队状态因素 | 15% | 不利因素综合分析 |
| 教练 | 10% | 主教练能力与履历档位 |
| 近20年战绩 | 10% | 世界杯、洲际杯、友谊赛，按时间衰减 |
| 足球强洲因素 | 5% | 大洲之间历史胜平负倾向 |
| 比赛环境 | 5% | 地理位置、主办地区适应度 |
| 黑马/爆冷 | 5% | 心理、战术克制、伤病、凝聚力等爆冷指数 |

公式：

```text
多因子得分 = 球队实力*35% + 排名差*15% + 球队状态*15% + 教练*10%
           + 近20年战绩*10% + 强洲因素*5% + 比赛环境*5% + 黑马/爆冷*5%
```

使用时分别为主胜、平局、客胜建立分值，然后归一化为多因子先验。多因子先验默认只影响最终胜平负 20%-30%；如果数据缺失较多，降到 10%-15%。

## 二、球队实力：FIFA积分差

| FIFA积分差 | 强队胜 | 平局 | 弱队胜 |
|------------|--------|------|--------|
| 0-50 | 55% | 90% | 45% |
| 50-100 | 60% | 80% | 40% |
| 100-200 | 70% | 60% | 30% |
| 200-300 | 80% | 40% | 20% |
| 300+ | 90% | 20% | 10% |

说明：图中平局列更像“接近程度/平局倾向分”，不是直接概率。使用时要乘以 35% 后再与其他因子共同归一化。

例：积分差 35，强队胜 55%、平局 90%、弱队胜 45%；乘以 35% 后得到 19.25、31.50、15.75。

## 四、球队状态因素

球队状态用于扣减一方胜率倾向，主要是负面因素。

大类权重：

| 大类 | 权重 | 子项 |
|------|------|------|
| 内部因素 | 40% | 更衣室矛盾 40%、年龄 20%、伤病程度 30%、其他管理 10% |
| 心理压力 | 25% | 舆论压力 30%、心理状态 70% |
| 对手策略 | 20% | 被恶意犯规 70%、被情绪挑动 30% |
| 其他因素 | 15% | 内部压力 70%、外部危机 30% |

等级扣减：

| 等级 | 影响百分比 |
|------|------------|
| A | 0% |
| B | -25% |
| C | -50% |
| D | -75% |

使用方法：为每个子项打 A/B/C/D，再按子项权重和大类权重求加权扣减。若没有可靠情报，不得臆测严重负面状态，默认 C 或标注缺失后降低该因子权重。

## 五、教练能力

| 教练档位 | 加成权益 |
|----------|----------|
| 第一梯队 | +12% |
| 第二梯队 | +8% |
| 第三梯队 | +5% |
| 第四梯队 | +2% |
| 第五梯队 | -2% |
| 第六梯队 | -5% |

图中示例：墨西哥主帅和韩国主帅都按第四梯队取 +3.5%，差值为 0，教练权益值为 0。

应用公式：

```text
教练权益 = (主队教练加成 - 客队教练加成) * 10%
```

如果无法确认当前主教练或档位，不使用该因子，或给双方 0。

| 时间间隔 | 单话题内剩余影响力 | 总体影响力取值 |
|----------|--------------------|----------------|
| 1年内 | 70%-85% | 29.25% |
| 2年 | 55%-70% | 23.58% |
| 3年 | 40%-55% | 17.92% |
| 5年 | 25%-40% | 12.26% |
| 8年 | 15%-25% | 7.55% |
| 10年 | 10%-20% | 5.66% |
| 15年 | 5%-10% | 2.83% |
| 20年+ | <5% | 0.94% |

赛事权重：

```text
历史战绩权益 = (世界杯取值*65% + 洲际杯取值*35% + 友谊赛取值*5%) * 10%
```

使用边界：越近、越正式、越同级的比赛越有价值。超过 20 年、阵容和教练变化过大的比赛只作弱参考。

## 八、地理环境影响

地区影响表：

| 地理位置 | 影响百分比 | 100%权益加成后 |
|----------|------------|----------------|
| 墨西哥 | 12.00% | 75.00% |
| 美国、加拿大 | 6.50% | 40.63% |
| 南美洲 | 3.50% | 21.88% |
| 欧洲 | -4.00% | -25.00% |
| 亚洲 | -7.00% | -43.75% |
| 非洲 | 0.00% | 0.00% |
| 中北美洲 | 5.00% | 31.25% |

公式：

```text
地理环境权益 = (主队地理权益 - 客队地理权益) * 5%
```

例：墨西哥 vs 韩国，75.00% - (-43.75%) = 118.75%，最终权益值 5.94%。

## 九、黑马/爆冷指数

爆冷指数用于修正强弱分明但存在结构性风险的比赛。

### 1. 黑马/爆冷指数分组

| 因素 | 权重 |
|------|------|
| 心理与压力 | 18% |
| 技术克制/被研究程度 | 18% |
| 伤病/缺阵情况 | 15% |
| 教练能力 | 15% |
| 团队凝聚力 | 10% |
| 天才球员 | 10% |
| 世界杯历史基因 | 7% |
| 小组与赛程 | 4% |
| 国内特殊情况 | 3% |

每个因素可细分为 0-20 分项目，例如大赛抗压、战术可预测性、核心依赖、替补深度、临场调整、团队认同、逆境韧性、赛程心理节奏、外部干扰等。

### 2. 动态平局公式

图中公式：

```text
P(draw) = Dmax * (1 - |Δ|)^k
```

- `Dmax`：最大平局率。
- `k`：衰减速度，足球取值约 1.2。
- `Δ`：两队综合实力差，通常来自双方 S 值差。

示例：S主队 0.457，S客队 0.168，实力差 0.289，得到主胜 58.96%、平局 19.37%、主负 21.67%。

应用边界：该公式适合判断“强弱差不大时平局是否应提高”，不能单独决定比分。

## 十、融合到当前 skill 的方式

1. 多因子公式先给出主胜/平/客胜先验。
2. 读取本届 54 场实时概率基线，校准平局率、总进球桶、半全场路径。
3. 读取双方本届已完赛轨迹，校准进球/失球上限。
4. 读取晋级路径，校准发力或降速。
5. 最终输出整数胜平负概率，总和为 100。
6. 若多因子公式和实时轨迹冲突，以实时轨迹和赛前情报为主，并在报告中写明冲突。
